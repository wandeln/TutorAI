Direktiven am Folienanfang (je eigene Zeile): layout: center|topleft|twocol, transition: fade|slide|zoom|none|autoanimate (Default: autoanimate — der Inhalt animiert zwischen den Folien ineinander; fade/slide/zoom/none setzen eine klassische Transition; gezoomte Applets ({zoom=X}) werden vom Auto-Animate übersprungen — der Applet-Zoom bleibt erhalten), class: <kennung>, notes: <Sprechernotiz>, background: ![Titel](/media/…) (Vollflächiger Folien-Hintergrund, deckt den ganzen Bildschirm ab — Bild oder .html-Applet; Applets bleiben in der Präsentation klickbar, dafür ist dann der Folieninhalt dieser Folie nicht. .html wird beim PDF-Export nicht mitgedruckt). Zweispaltig: layout: twocol + eigene Zeile || (eine Überschrift auf der ersten Zeile der linken Spalte spannt über beide Spalten). Vertikale Unterfolien: eine eigene Zeile -- teilt eine Folie in mehrere Unterfolien, die in der Präsentation nacheinander (mit ↓) erscheinen — jede Unterfolie ist wie eine normale Folie (eigene Direktiven, notes, Hintergrund; --- trennt weiterhin Folien). Max-Bildhöhe in px: {% raw %}{height=400}{% endraw %} (Suffix px und führender Punkt optional) und Applet-Zoom: {% raw %}{zoom=1.5}{% endraw %}, Applet-Max-Höhe: {% raw %}{height=300}{% endraw %} (direkt nach dem Bild-/Applet-Snippet). Schrittweises Einblenden: {% raw %}{#fragment}{% endraw %} am Zeilenende (z. B. nach Bullet, Absatz oder Formel); {% raw %}{#fragment:id}{% endraw %} → alle Elemente mit gleicher ID erscheinen gleichzeitig; {% raw %}{#Fragment}{% endraw %} (Großbuchstabe) → Element + alle folgenden Inhalte der Folie erscheinen erst mit einem Klick. Hervorheben: @box:highlight … @endbox packt den Inhalt in eine transparente, geblurte Box in der Primärfarbe (z. B. für Titel auf Deckslides); erste Zeile @boxcolor:<farbe> (z. B. @boxcolor:white) übersteuert die Boxfarbe (Hex, rgb()/rgba(), CSS-Farbname). Formelteile schrittweise: {% raw %}\htmlClass{fragment}{…} / \htmlClass{fragment:id}{…}{% endraw %} in einer Formel → der eingewickelte Teil erscheint erst mit einem extra Klick (gleiche id = gleichzeitig). Auto-Animate-Element-ID: {% raw %}{#aaid:label}{% endraw %} am Zeilenende (oder nach $$…$$/{% raw %}{#eq:…}{% endraw %}/Bild-Snippet) → Elemente mit demselben Label auf zwei Folien animieren per ID ineinander. Code: Fenced-Block mit Sprache auf der öffnenden Zeile wird syntax-highlightet; {% raw %}{#lines:1,3-5}{% endraw %} nach der Sprache → Zeilennummern + schrittweises Zeilen-Einblenden (| = weiterer Schritt); @box:code … @endbox = dunkle Code-Box mit „Code“-Kopf.
